# Store listing copy — Margin Notes

## Name
Margin Notes — notes beside PDFs, web pages & videos

## Short description (Chrome Web Store, ≤132 chars)
Notes beside anything: PDFs (per page), web pages (per section), videos (per timestamp). Handwriting, Markdown, all local.

## AMO summary (≤250 chars)
A notebook that docks next to what you read or watch. PDFs get a note per page, web pages a note per section, YouTube and other videos a note per timestamp (click to jump back). Markdown, stylus handwriting, export. Everything stays on your device.

## Detailed description

**Read on one side, write on the other.**

Margin Notes turns the empty space beside a document into a notebook that stays linked to *where* you are.

**PDFs** — Every PDF you open lands in a split view: PDF left or right, notes in the free space. One note per page (plus a document note), following you as you scroll — pin to hold a page. Select text → *Add to notes* quotes it. Fit width/page, zoom, rotate, find, outline, deep links, resume where you left off. Notes are keyed to the PDF's fingerprint, so they survive renames, moves and re-downloads.

**Web pages & articles** — Click the toolbar icon → *Notes for this tab*. The page stays a normal tab; your notes open in the side panel and follow the *section* you're reading (by headings). Select text on the page → *Add to notes*. Works on documentation, papers, blogs, course platforms — any site.

**Videos** — On YouTube (or any page with a video) the panel switches to time mode: press *＋ note here* while watching and the note is anchored to that second. Later, click the note — or a `12:34` typed anywhere in your notes — and the video jumps there. Notes follow playback. Export writes YouTube time links.

**Handwriting** — Draw mode gives every page/section/timestamp its own sketch pad (pen, highlighter, eraser, pressure, ruled/grid/dot paper, undo). On PDFs, Annotate mode writes directly on the pages, stored in PDF coordinates so it stays put across zoom. Export as PNG.

**Markdown notes** — Live preview, lists, tasks, quotes, code, `p.12` / `12:34` jump links, Ctrl+B/I, word count, autosave.

**Local & yours** — Everything lives in your browser (IndexedDB). Export as Markdown or JSON, back up / restore from Settings. No account, no server, no tracking. Light/dark themes, keyboard-first, Chrome and Firefox.

Also: split view for local HTML / Markdown / text / images and any page that allows embedding; a library page listing everything you've annotated; right-click *Open link in Margin Notes*.

## Permission justifications (CWS "Privacy practices" tab)

- **declarativeNetRequest / webRequest / webNavigation** — Redirect PDF navigations (by `.pdf` URL, by `application/pdf` content-type, and `file://`) into the extension's viewer, and detect when a framed page has loaded so the page agent can be attached. webRequest is observe-only (no blocking).
- **scripting** — Inject the page agent (`viewer/frame-agent.js`) into the single tab or frame the user has opened notes for. It reports headings, current section, `<video>` time and user-selected text; nothing else, nothing remote.
- **Host permission `<all_urls>`** — Needed to fetch PDFs from any site the user opens, to inject the page agent into any site the user chooses to annotate, and for the content-type sniff. The extension acts only on tabs the user explicitly opens notes on (plus PDF navigations, which can be turned off).
- **tabs** — Read the active tab's URL/title so the side panel knows which page's notes to show; open the viewer.
- **sidePanel** — Host the notes beside a normal tab.
- **storage / unlimitedStorage** — Settings (sync) and notes/handwriting (IndexedDB), which can grow large with ink.
- **contextMenus** — *Take notes on this page*, *Open in split view*, *Open link in Margin Notes*.
- **Remote code** — None. All code ships in the package (pdf.js bundled).
- **Data use** — No user data is collected or transmitted. See PRIVACY.md.

## Firefox (AMO) notes
- Package: `dist/margin-notes-firefox-<v>.zip` (built by `npm run build`; passes `web-ext lint` with 0 errors — warnings are the guarded `chrome.sidePanel` calls and pdf.js dynamic imports).
- Sidebar: `sidebar_action` hosts the same panel. Host permission is opt-in on Firefox; the landing page shows an *Allow access to websites* button.
- Data collection declaration: `none` (set in `browser_specific_settings.gecko.data_collection_permissions`).
- Source is unminified; no build step is required to reproduce (`ext/` + `scripts/build.mjs`).
